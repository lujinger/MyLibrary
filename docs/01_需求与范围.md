# 01 · 需求与范围（v0.1.0）

> 项目：MyLibrary —— 个人藏书管理系统
> 版本：v0.1.0（一期）
> 状态：已交付（89 个测试用例全绿）
> 关联文档：[02_数据库设计](./02_数据库设计.md) · [03_API契约](./03_API契约.md) · [04_安全与设计决策](./04_安全与设计决策.md)

## 1. 项目定位

MyLibrary 帮助"书的主人"管理自己的实体藏书：

1. **图书目录**：录入、检索、维护自己的书目。
2. **组织归类**：用"图书馆"作为容器对书分组（类似文件夹的增强版）。
3. **借出登记**：把书借给谁、何时借出、约定何时还、是否已归还 —— 由书主人登记。

> 语义澄清：一期是 **"书主人登记借出"** 模式（个人记账式），不是"读者主动发起借阅 + 审批"的图书馆流通系统。后者列入二期候选。

## 2. 术语与核心语义

| 术语 | 定义 | 关键规则 |
|---|---|---|
| 用户 User | 系统使用者，书的拥有者 | 注册成功后由信号自动创建默认图书馆"我的图书馆" |
| 图书馆 Library | 书的**容器** | 一人可建多馆，`(owner, name)` 唯一；默认馆不可删除 |
| 图书 Book | 一本藏书 | **必须归属一个馆**；馆删除时书级联删除；`owner` 恒为创建者 |
| 借阅记录 BorrowRecord | 一次借出 = 一条记录 | 归还只更新 `return_date`；一本书同时最多一条在借记录；状态由 `return_date` 派生 |

核心语义决策：

- 注册 → 自动建默认馆（`post_save` 信号，`raw=True` 时跳过以兼容 fixtures/迁移）
- 书必须挂在馆里（`library` 非空外键）
- 删馆 → 级联删书（`on_delete=CASCADE`）
- 默认馆禁删、书不可"无馆漂流"

## 3. 功能范围（一期）

### 3.1 认证模块（auth）

| 能力 | 接口 | 说明 |
|---|---|---|
| 注册 | `POST /user/register` | 成功返回 token，并自动创建默认馆 |
| 登录 | `POST /user/login` | 换取 JWT（access 30min / refresh 7d） |
| 我的信息 | `GET /user/me` | 当前登录用户资料 |

### 3.2 图书模块（book）

| 能力 | 接口 | 说明 |
|---|---|---|
| 书列表 | `GET /book` | 分页（`page_size` 上限 50）；`keyword` 模糊搜书名/作者；`library_id` 过滤 |
| 新增书 | `POST /book` | 必须指定归属馆；`borrow_status` 默认 available |
| 书详情 | `GET /book/<book_id>` | 仅本人可见 |
| 更新书 | `PUT/PATCH /book/<book_id>` | 可更新借阅状态等字段 |
| 删除书 | `DELETE /book/<book_id>` | 仅本人可删 |

### 3.3 图书馆模块（library）

| 能力 | 接口 | 说明 |
|---|---|---|
| 馆列表 | `GET /library` | 附带每馆书数量（annotate） |
| 新建馆 | `POST /library` | 同名馆返回 400 |
| 馆详情/更新 | `GET/PUT/PATCH /library/<library_id>` | 默认馆信息可改，但不可删 |
| 删除馆 | `DELETE /library/<library_id>` | 默认馆 400；普通馆删除**连带删除馆内所有书** |
| 批量移书入馆 | `POST /library/<library_id>/books` | 校验书归属本人 |
| 移出书（回默认馆） | `DELETE /library/<library_id>/books/<book_id>` | 默认馆不可作为移出源 |

### 3.4 借阅模块（borrow）

| 能力 | 接口 | 说明 |
|---|---|---|
| 登记借出 | `POST /borrow` | `book_id` + `borrower_name`（可选 `due_date`，不得早于今天）；书须存在、属于本人、`borrow_status=available`；建记录 + 置书 borrowed 在同一事务 |
| 归还 | `POST /borrow/<record_id>/return` | 写入 `return_date` 并把书恢复 available；重复归还 400 |
| 借阅列表 | `GET /borrow` | 分页；`status=borrowing/returned` 过滤 |

## 4. 明确不做（一期边界）

以下需求**有意排除**在一期之外，防止范围蔓延：

- ❌ 读者主动借阅 / 借阅审批流（`borrower` 外键化 + 审批状态机）—— 二期候选
- ❌ 图书共享权限（`Book.permission`：私有/好友可见/公开）—— 二期候选
- ❌ 好友 / 社交体系
- ❌ 逾期提醒、消息通知
- ❌ ISBN / 外部元数据抓取
- ❌ 多端（小程序/App）—— 仅提供 REST API

## 5. 非功能需求

| 维度 | 要求 |
|---|---|
| 安全 | 全部业务接口要求 JWT 认证；所有资源按 `owner` 过滤（防水平越权 IDOR） |
| 数据一致性 | 借出/归还使用 `transaction.atomic`；在借唯一性由数据库部分唯一约束兜底 |
| 性能 | 列表分页（`page_size` ≤ 50）；外键查询 `select_related` 防 N+1 |
| API 文档 | drf-spectacular 自动生成（schema + docs 页面） |
| 测试 | Django `APITestCase`，一期累计 89 个用例全绿（认证 21 + 图书 24 + 图书馆 22 + 借阅 22） |
